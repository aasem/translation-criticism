Method

Each report judges a submitted translation by how it departs from its source, not by how the reviewer would have translated it. The source is split into sentence-level segments, and the submission is set beside it, segment by segment. Every departure gets one code and one severity.

The codes adapt Multidimensional Quality Metrics, the translation industry's standard error framework, to literary prose. A covers accuracy (what the source says), B covers the correctness of the target text, and C covers style (how the source sounds). Interference (C4) is reported as a pattern rather than counted segment by segment.

Severity. Minor affects nuance, tone or texture. Major changes what the sentence says. Critical breaks a sentence the passage depends on: its key claim, turn or image.

Stakes. Each report is set at Standard, Literary or Canonical stakes. Stakes do not change the severity of single deviations. They set how work-level findings are graded and how high the bar is for the decision.

Decision. Each report ends with one step on a five-step scale, from Accept to Reject. A sample is taken to represent the whole work.
